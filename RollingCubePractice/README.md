# 바닥 모서리를 기준으로 굴러가는 육면체

RollingCubePractice.sln을 열고 Debug / x64에서 Ctrl+F5로 실행한다.

| 입력 | 기능 |
| --- | --- |
| W / A / S / D | 누르는 동안 앞(-z) / 왼쪽(-x) / 뒤(+z) / 오른쪽(+x)으로 한 칸씩 구르기 |
| Space | 현재 각도에서 일시정지 / 이어서 시작 |
| C 또는 I | 위치·자세·카메라 초기화 |
| ESC 또는 Q | 종료 |

한 변이 1인 큐브가 바닥 모서리를 축으로 90도씩 구른다.
중심만 이동시키면서 자전하는 방식이 아니라, 회전 중 중심도 모서리 주위의 원호를 따라 움직인다.
자동 경로 이동 대신 WASD로 조종한다. 시작할 때는 멈춰 있고 키를 누르면 해당 방향으로 구른다.
키를 놓으면 진행 중인 90도 회전까지만 끝내고 멈춘다. 회전 중 다른 방향을 누르면 다음 칸부터 반영한다.
한 칸 이동 후 큐브 전체가 방 안에 있을 때만 시작하므로 벽을 뚫지 않는다.
이동 방향은 카메라 방향이 아니라 월드 xz축 기준이다. 두 키 이상을 누르면 W, S, A, D 순서로 하나만 선택한다.
각 면을 다른 색으로 표시해 자세 변화를 구분한다.

| 기능 | 담당 함수 |
| --- | --- |
| 현재 진행 방향·회전 각도 | RollingCube 구조체 |
| WASD 입력과 다음 방향 | ProcessInput |
| 방 경계 확인과 한 칸 시작 | StartRoll |
| 90도마다 중심과 누적 자세 저장 | CompleteRoll |
| 시간에 따라 회전 각도 증가 | Update |
| 접촉 모서리 기준 회전 | GetRollingTransform |
| 육면체 출력 | DrawRollingCubeScene |

행렬은 `T(모서리) × R(각도) × T(-모서리) × T(현재 중심) × 누적 회전`이다.
회전축은 위쪽 방향과 진행 방향의 외적으로 구한다.
회전 완료 시 정점 배열을 수정하지 않고 중심과 누적 회전 행렬만 갱신한다.



## 23번과 같은 육면체 방

바닥·천장·왼쪽·오른쪽·앞·뒤의 여섯 면을 서로 다른 색으로 그린다.
방 범위는 x/z 각각 -6~6, y는 0~6이다.
InitRoomBuffer는 각 면의 안쪽이 정면이 되도록 정점 순서를 만들고, DrawRoomScene은 방과 바닥 격자를 그린다.

GL_CCW와 GL_BACK 컬링을 사용하므로 밖에서 바라보는 가까운 벽의 바깥쪽은 사라지고 반대편 벽의 안쪽이 보인다.
카메라가 다른 쪽으로 공전하거나 방 안으로 들어가면 보이는 벽도 달라진다.
카메라 위치로 벽을 직접 켜고 끄는 조건문은 사용하지 않는다.
객체는 바깥쪽이 정면인 육면체이므로 방과 반대 방향의 정점 순서를 사용한다.
문 열기나 장애물은 추가하지 않고 기존 예제의 객체 움직임과 카메라 명령을 유지했다.

## 공통 카메라 조작

| 입력 | 기능 |
| --- | --- |
| x / Shift+x | 누르는 동안 월드 x축 양 / 음 방향 이동 |
| z / Shift+z | 누르는 동안 월드 z축 양 / 음 방향 이동 |
| y / Shift+y | 카메라 제자리에서 양방향 회전. 같은 방향 키를 다시 누르면 정지 |
| r / Shift+r | 장면 원점의 y축 주위로 양방향 공전. 같은 방향 키를 다시 누르면 정지 |
| + / - | 누르는 동안 시선 목표 쪽으로 줌인 / 반대로 줌아웃. 숫자패드도 지원 |
| p / Shift+p | 원근 투영 / 직각 투영 |
| C 또는 I | 객체와 카메라 전체 초기화 |

대문자는 Shift와 해당 키를 함께 누른다.
r/R은 공전 명령이므로 초기화는 C/I로 옮겼다.
방향키와 Space는 각 예제의 기존 기능을 유지한다.
객체 애니메이션을 Space로 멈춰도 카메라 이동과 회전은 계속 사용할 수 있다.
제자리 회전과 공전은 서로 독립적이므로 동시에 켤 수 있다.
x/z 이동은 월드 축 기준이고 +/- 줌은 현재 바라보는 방향 기준이다.

ResetCamera는 초기 위치와 시선을 설정하고, ProcessCameraInput은 이동·줌을 처리한다.
UpdateCamera는 자전·공전 행렬을 적용하고, ProcessCameraKey는 회전 토글과 투영 모드를 바꾼다.
DrawScene은 현재 카메라 상태로 view와 projection을 만들어 셰이더에 전달한다.

## 파일 구성과 학교 PC 실행

main.cpp와 PracticeStarterGL.h 및 shaders 폴더가 모두 포함되어 있다.
학교용 전체 묶음 ZIP에서는 상위 폴더의 externals를 자동 사용한다.
이 폴더만 옮긴다면 externals.zip을 풀어 폴더 안에 externals를 넣는다.
셰이더와 DLL은 빌드할 때 실행 파일 옆에 자동 복사된다.
