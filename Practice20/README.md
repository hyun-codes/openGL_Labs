# Practice20

높이 1.1의 ㄱ자 컨베이어 위에서 번호와 색상이 다른 상자 5개가 순서대로 움직인다.
벨트 상면은 평면 메시이며, 표면 줄무늬·프레임·지지대·상자·숫자는 육면체 버퍼를 재사용한다.
코너에서는 위치와 방향이 함께 변하고, 끝에 도착한 상자는 시작으로 돌아온다.

| 키 | 기능 |
| --- | --- |
| b | 벨트와 상자의 이동 시작/정지 |
| + / 숫자패드 + | 누르는 동안 카메라가 가까워져 줌인. = 키도 지원 |
| - / 숫자패드 - | 누르는 동안 카메라가 멀어져 줌아웃 |
| p | 원근 투영 |
| Shift+p | 직각 투영 |
| 왼쪽 / 오른쪽 방향키 | 중심 y축 주위로 카메라 회전 |
| r | 벨트 위치·상자·카메라·투영 초기화 |
| q | 종료 |

초기 상태는 이동 중이며, 카메라의 높이 각도는 고정된 3인칭 쿼터뷰이다.
`GetPathPose`가 경로 위의 위치와 방향을 반환한다. 벨트 줄무늬와 모든 상자가 이 함수를 공유한다.
`Update`는 이동 거리만 바꾸고, `DrawScene`에서 원근/직각 투영과 카메라를 설정한 뒤 장면을 그린다.
번호 1~5는 일곱 개의 막대 조합으로 만들어 별도 글꼴이나 텍스처가 필요 없다.

Visual Studio에서 Practice20을 시작 프로젝트로 지정하고 x64로 실행한다.
