# Practice17

화면 중앙 좌표축과 두 OBJ 객체에 모델링 변환을 적용한다. 좌표축과 도형은 x/y축에 대해 30도 기울어져 있다.

Visual Studio에서 Practice17을 시작 프로젝트로 지정하고 Debug 또는 Release / x64로 실행한다.
`models`의 OBJ 파일과 `shaders`는 빌드 시 실행 폴더로 복사된다. 처음에는 구와 원숭이가 표시된다.

## 키보드

| 키 | 동작 |
| --- | --- |
| 1 / 2 / 3 | 초기 왼쪽 객체 / 초기 오른쪽 객체 / 두 객체 선택 |
| x / Shift+x | 로컬 x축 양 / 음 방향 자전 |
| y / Shift+y | 로컬 y축 양 / 음 방향 자전 |
| r / Shift+r | 중앙 y축 양 / 음 방향 공전 |
| a / Shift+a | 도형 중심에서 확대 / 축소 |
| b / Shift+b | 원점을 기준으로 위치와 크기를 함께 확대 / 축소 |
| d / Shift+d | x축 왼쪽 / 오른쪽 이동 |
| e / Shift+e | y축 위 / 아래 이동 |
| t | 두 객체가 원점을 통과해 현재 자리를 교환 |
| u | 두 객체가 위 / 아래 곡선으로 현재 자리를 교환 |
| v | 두 객체의 반대 방향 확대·축소와 자전·공전 시작 / 정지 |
| c | 초기 왼쪽 객체를 cone.obj, 초기 오른쪽 객체를 torus.obj로 변경 |
| s | 도형, 선택, 애니메이션을 초기화 |
| q | 종료 |

`x/y/r/a/b/d/e`는 키를 누른 동안 동작한다. `t/u/v/c`는 항상 두 객체에 적용된다.
자리 교환 도중 `t/u`를 누르면 현재 위치에서 새 이동을 시작한다. `v`와 수동 변환은 함께 사용할 수 있다.
모델을 바꿔도 현재 도형의 위치, 회전, 크기는 유지된다.
C를 다시 눌러도 원뿔·토러스가 유지되며, S로 초기화하면 구·원숭이로 돌아간다.

## 코드 흐름

`InitBuffer`가 OBJ를 한 번 읽고 VAO/VBO를 만든다.
`ObjectState`는 각 도형의 위치, 회전, 크기와 사용할 모델을 관리한다.
`Update`에서 시간에 따라 상태를 바꾸고, `DrawScene`은 `base * translate * rotation * scale` 행렬을 셰이더에 전달한다.
`ObjectAnimation.h`에는 자전·공전·스케일·자리 교환 계산이 있다.

구의 자전도 보이도록 정점 위치에 따라 색을 보간한다. OBJ는 로컬 원점을 중심으로 정규화한다.
모델 파일은 삼각형 면과 볼록 다각형 면, 양수/음수 위치 인덱스를 지원하며 텍스처·재질은 사용하지 않는다.
