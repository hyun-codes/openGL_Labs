# Practice22

실습 19의 탱크와 모든 조작을 가져와 같은 장면을 세 뷰포트에 출력한다.

| 화면 | 투영과 카메라 |
| --- | --- |
| 왼쪽 큰 화면 | 실습 19의 카메라를 이용한 원근 투영 |
| 오른쪽 위 | xz 평면도. 위에서 내려다보는 직각 투영 |
| 오른쪽 아래 | xy 정면도. +z 쪽에서 보는 직각 투영 |

`Update`는 프레임마다 한 번 실행하며, `DrawScene`에서 동일한 탱크를 카메라·투영만 바꾸어 세 번 그린다.
`glViewport`로 출력 위치를 정하고, `glScissor`로 화면과 깊이 버퍼 초기화가 다른 뷰포트를 지우지 않도록 한다.
창 크기를 바꾸면 세 영역과 각각의 종횡비를 다시 계산한다.

## 조작

- 방향키: 탱크를 월드 xz 평면에서 이동. 세 화면에 같은 상태가 반영된다.
- d / t / l / g / p: 아래 몸체 높이 변화 / 중앙 몸체 회전 / 상부 자리 교환 / 포신 회전 / 깃대 회전.
- x / Shift+x, z / Shift+z: 원근 화면의 카메라를 x축·z축 양/음 방향으로 이동.
- y / Shift+y: 원근 화면의 카메라 자전. 같은 방향을 다시 누르면 정지.
- r / Shift+r: 원근 화면의 카메라 공전. 같은 방향을 다시 누르면 정지.
- o: 모든 화면의 객체 색상을 함께 변경.
- c: 탱크와 원근 카메라 초기화.
- q: 종료.

평면도·정면도의 카메라는 고정이다. xy 정면도에서는 z축 이동이 화면 안팎 방향이므로 위치가 좌우로 움직이지 않는 것이 정상이다.
기존 Practice19 프로젝트는 변경하지 않는다. Practice22를 시작 프로젝트로 지정하고 x64로 실행한다.
