# Practice21

원근 투영, 깊이 테스트, 뒷면 컬링을 적용한 3차원 공 튕기기 실습이다.
기존 `InitBuffer → Update → DrawScene` 구조를 사용한다.

방은 안쪽이 정면인 평면 5개로 구성되어 있으며, 정면은 관찰을 위해 그리지 않는다.
공이 내부에서 튕기도록 정면 쪽에도 보이지 않는 물리 경계를 둔다.
초기 공 1개와 z축을 따라 배치한 서로 다른 크기의 육면체 3개가 있다.

| 입력 | 기능 |
| --- | --- |
| B 또는 b | 공 추가 및 이동 시작, 동시에 최대 5개 |
| z / Shift+z | 누르는 동안 공간을 z축 양/음 방향으로 이동 |
| y / Shift+y | 화면 y축 기준 시계/반시계 방향 회전. 같은 방향 키를 다시 누르면 정지 |
| 왼쪽 버튼을 누른 채 좌우 드래그 | 공간을 z축 기준으로 기울임 |
| o | 현재 회전 상태에서 가장 아래를 향하는 면 열기/닫기 |
| r | 공·육면체·공간·바닥을 초기 상태로 되돌리기 |
| q | 종료 |

이미지에 바닥 열기 키가 지정되어 있지 않아 O를 사용한다.
O로 열 때 현재 공간의 회전을 기준으로 아래를 향하는 면을 선택한다. 열린 뒤 회전해도 선택한 면을 유지하며, 다시 O를 누르면 그 면이 닫힌다. 완전히 닫은 후 다시 열면 아래쪽 면을 새로 선택한다.
기울어진 공간의 좌표계로 중력을 변환하므로 육면체는 바닥의 낮은 쪽으로 미끄러진다.
공은 반지름, 육면체는 실제 크기를 고려하여 벽과 충돌한다. 공은 작은 육면체에 맞아도 튕긴다.
모든 공은 초당 2.5의 일정한 속도로 움직이며, 벽이나 육면체에 닿으면 속력을 유지한 채 방향만 반사한다. 공에는 중력·가속·감속을 적용하지 않는다.
바닥이 열리면 육면체는 떨어지고, 공은 아래로 향할 때 열린 바닥으로 빠져나간다. R로 초기화할 수 있다.
방 밖으로 멀리 떨어진 공은 제거되어 B로 다시 추가할 수 있다.

구는 위도·경도 삼각형으로 한 번 생성하고, 모든 공이 같은 VAO/VBO를 재사용한다.
벽은 안쪽 방향, 구와 육면체는 바깥쪽 방향이 CCW가 되도록 정점을 구성한다.
`UpdatePhysics`는 작은 시간 간격으로 나누어 충돌과 낙하를 계산한다.

Visual Studio에서 Practice21을 시작 프로젝트로 지정하고 x64로 실행한다.
