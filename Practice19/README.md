# Practice19

`InitBuffer → Update → DrawScene` 구조로 원근 투영과 깊이 테스트를 적용한 탱크를 그린다.
육면체 하나의 VAO/VBO를 아래 몸체 2개, 중앙 몸체, 상부 몸체 2개, 포신, 깃대와 깃발에 재사용한다.

| 키 | 기능 |
| --- | --- |
| 방향키 | 누르는 동안 탱크를 월드 xz 평면에서 이동 |
| d | 아래 몸체 높이 확대·축소 애니메이션 시작/정지 |
| t | 중앙 몸체 y축 회전 시작/정지 |
| l | 상부 몸체 두 개가 반대쪽 곡선 경로로 자리를 교환 |
| g | 두 포신이 연결 지점을 기준으로 y축 반대 방향 회전 시작/정지 |
| p | 두 깃대가 연결 지점을 기준으로 x축 반대 방향 회전 시작/정지 |
| x / Shift+x | 누르는 동안 카메라를 월드 x축 양/음 방향 이동 |
| z / Shift+z | 누르는 동안 카메라를 월드 z축 양/음 방향 이동 |
| y / Shift+y | 카메라 자신의 y축 시계/반시계 방향 자전. 같은 방향 키를 다시 누르면 정지 |
| r / Shift+r | 화면 원점의 y축 시계/반시계 방향 공전. 같은 방향 키를 다시 누르면 정지 |
| o | 바닥과 탱크 부품 색상 변경 |
| c | 카메라·탱크·색상·애니메이션 초기화 |
| q | 종료 |

각 애니메이션은 현재 변환 상태를 유지하면서 함께 실행된다. L을 연속 입력하면 각 입력마다 180도 이동을 이어서 수행한다.
`BuildTankParts`에서 부모 행렬을 자식 부품에 전달하며, `KeepTankOnFloor`는 움직이는 부품의 꼭짓점까지 검사해 바닥 밖으로 나가지 않게 한다.
카메라 자전은 위치를 바꾸지 않고 시선을 회전하며, 공전은 위치·시선·위쪽 방향을 함께 회전한다.
