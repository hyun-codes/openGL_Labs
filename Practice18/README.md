# Practice18

중심 구, 서로 다른 경로·속도의 행성 3개와 달 3개를 그린다.
행성 궤도는 xz 평면과 그 평면을 z축 기준으로 ±45도 기울인 것이다.
달의 기본 궤도는 화면과 평행하며 모든 공전 경로를 표시한다.

| 키 | 기능 |
| --- | --- |
| p / Shift+p | 직각 투영 / 원근 투영 |
| m / Shift+m | 솔리드 / 와이어 |
| W / A / S / D | 누르는 동안 전체 장면을 위 / 왼쪽 / 아래 / 오른쪽 이동 |
| + / - | 전체 장면을 z축 양 / 음 방향으로 이동. = 키와 숫자패드도 지원 |
| 1 | 모든 행성·달 궤도 반지름을 1.25배로 확대 / 원래 크기로 복원 |
| 2 | 중심 구의 크기·색상 변화 애니메이션 시작/정지 |
| 3 | 행성 z축 기준 달 궤도 회전 시작/정지. 달도 회전된 궤도를 따라 이동 |
| H | 은면제거 토글 |
| R | 초기화 |
| Q | 종료 |

1·2·3은 서로 독립적으로 동작한다. 1은 확대/원래 크기 토글이며, 2·3은 멈춰도 현재 크기·색상·회전 상태를 유지한다.
행성과 달의 기본 공전은 계속 진행된다. 3을 실행하기 전 기본 달 궤도는 화면과 평행하고, 실행하면 추가 회전이 적용된다.
전체 장면의 이동은 카메라 이동이 아니라 공통 모델 행렬의 이동이다.
원형 버퍼는 반지름 1로 한 번 만들고 그릴 때 반지름을 적용하므로 반지름이 변해도 VBO를 다시 만들지 않는다.
1의 반지름 배율은 기본 1.0배 / 확대 1.25배이며, 중심 구의 반지름은 0.30~0.60 범위이다.

`InitBuffer → Update → DrawScene` 구조를 유지한다.
OBJ는 `models/sphere.obj`를 사용하며 빌드할 때 셰이더와 함께 실행 폴더로 복사된다.
Visual Studio에서 Practice18을 시작 프로젝트로 지정하고 x64로 실행한다.
